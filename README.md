# SaiFollowers — Frontend Demo

A responsive, frontend-only social media services panel built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run:
```bash
python -m http.server 3000
```

## Features
- Responsive dashboard and mobile navigation
- Demo service catalog and order form
- Order history and wallet screens
- Local profile demo
- LocalStorage-based demo state

## Important
This is a UI prototype only. It does not deliver followers, views or other services, process payments, send email, or provide real authentication. Do not enter real passwords or payment details. All demo data stays in the browser's LocalStorage.

## Tech
HTML5 · CSS3 · Vanilla JavaScript · Lucide icons
